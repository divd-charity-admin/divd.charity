# DIVD.Charity

Website: https://divd.charity

This repository contains the static website for DIVD.Charity, a public-benefit organisation focused on education, mentorship, entrepreneurship, and community development.

## Project goals

- Present a professional, trustworthy public-benefit website
- Preserve the existing DIVD identity and visual language
- Support static hosting on GitHub Pages with no server-side runtime
- Provide accessible, multilingual-friendly content with strong metadata
- Keep public transparency and governance information easy to find

## Structure

- `index.html` — homepage
- `about/` — organisation and governance overview
- `projects/` — current and future programmes
- `impact/` — impact and outcomes
- `team/` — leadership and governance information
- `get-involved/` — participation and volunteering
- `news/` — news and updates archive
- `anbi/` — ANBI transparency portal
- `privacy/` — privacy and disclosure policy
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

## Development notes

- The website is static and deploys to GitHub Pages without a production server.
- Use relative paths for static assets so the site works correctly in GitHub Pages.
- Keep metadata, accessibility and SEO content aligned with the public commitments of the organisation.
- Documentation and public transparency pages should remain simple, clear and easy to review.

## Deployment

Push to the default branch and GitHub Actions will deploy the site to GitHub Pages.
